# gretto Media Player (Android)

1. Open this folder in Android Studio (Koala or newer) and let Gradle sync.
2. Run on a device/emulator, or Build > Build APK(s).

Before release: replace UPDATE_URL in MainActivity.java and don't ship API_KEY hard-coded in the app.

## Get an APK without Android Studio
Upload this folder to a new GitHub repository (keep the .github folder). Open the
Actions tab > "Build APK" > latest run > download "gretto-apk" (app-debug.apk), then install it on your phone.
